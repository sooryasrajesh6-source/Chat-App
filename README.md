# 💬 Real-Time Chat Application

A real-time multi-user chat application built using **Node.js**, **Express.js**, and **Socket.IO**.

This project was created as a learning project to understand real-time communication, client-server architecture, and event-driven programming using Node.js.

## 🚀 Features

* Real-time messaging
* Multiple users in a single chat room
* Online users list
* User join and leave notifications
* Online user count
* Message timestamps
* Emoji picker
* Responsive interface
* Dark Pink Theme UI
* Socket.IO powered communication

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Node.js
* Express.js
* Socket.IO

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/your-username/chat-app.git
```

2. Navigate to the project folder

```bash
cd chat-app
```

3. Install dependencies

```bash
npm install
```

4. Start the server

```bash
node server.js
```

5. Open your browser

```text
http://localhost:3000
```
